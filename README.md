# Paramount 🧮🏆

Welcome to the official repository for **Paramount**, an interactive inter-university Mathematics Quiz Competition website. This platform is designed to host engaging mathematical challenges for university students, featuring a clean user interface and dynamic quiz functionality.

*The site is deployed via GitHub Pages.*

## ✨ Features
*   **Interactive Quiz Interface:** Built to seamlessly present math problems and capture user answers.
*   **Inter-University Focus:** Tailored for a competitive academic environment.
*   **Responsive Design:** Accessible and readable across various devices.
*   **Dynamic Logic:** Powered by JavaScript for real-time answer checking and scoring.

## 🛠️ Technologies Used
*   **HTML5:** Structure and content of the web pages (`index.html`).
*   **CSS3:** Styling, layout, and visual presentation (`style.css`).
*   **Vanilla JavaScript:** Core quiz logic, interactivity, and DOM manipulation (`script.js`).

## 📁 Repository Structure
Based on the current branch, the project files are organized as follows:

*   `index.html` - The main entry point and structural layout of the website.
*   `style.css` - Contains all the cascading stylesheets for the UI design.
*   `script.js` - Houses the JavaScript logic for the quiz competition.
*   `images/` - Directory containing visual assets used across the site.
*   `favicon.svg` - The website's favicon.
*   `CNAME` - Configuration file for custom domain routing via GitHub Pages.

## 💻 Getting Started (Local Development)
To run this project locally on your machine, follow these simple steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/virajisuranga101-alt/paramount60.git
   ```
2. **Navigate to the project directory:**
   ```bash
   cd paramount60
   ```
3. **Open the application:**
   Simply double-click the `index.html` file to open it in your default web browser. Alternatively, you can use an extension like VS Code's "Live Server" for a better development experience.
